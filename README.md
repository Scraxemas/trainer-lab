# Trainer Lab — Pixel Character Creator

Live website: **https://scraxemas.github.io/trainer-lab/**

A standalone, browser-based Gen 4/5-inspired pixel character creator with original starter artwork and support for private local sprite-pack imports.

## Features
- Live trainer customization (body, hairstyles, outfit, colors and accessories)
- Directional sprites and animated walking preview
- Randomize appearance, save presets locally and export PNGs
- **Sprite Vault:** drag/import a ZIP of transparent PNG sprites or choose an extracted folder
- Search sprite gallery, overlay aligned transparency layers or replace the complete trainer sprite
- Client-side imports: external sprite packs are processed in the browser, **not uploaded to the hosting service**

## Run locally

Open `index.html` in a modern browser. No installation or build step needed.

## Publish

Hosted with GitHub Pages from `main` branch `/(root)`. All deployment content is in `index.html`.

## Assets and IP

The built-in art is original procedural artwork. **No Nintendo Pokémon artwork, ROM dumps, or third-party sprite packs are included in this public repository.** Obtain creator-provided resources at the links in the app and only import packs you are permitted to use. Gen 4/5 refers to art-style inspiration and compatibility with locally imported sprite packs, not any Pokémon affiliation.

Trainer Lab is an unofficial fan project and is not affiliated with Nintendo, The Pokémon Company or Game Freak.

Maintained separately from the private `pokemon-asset-master` project. The private repository and its contents are not deployed to Pages.
